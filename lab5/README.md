# lab4

## Опис проєкту
  Проєкт є мобільним застосунком-каталогом товарів, розробленим за допомогою **React Native**, **Expo** та **Expo Router**. Основна ідея застосунку — продемонструвати побудову навігації за принципом **file-based routing**, реалізувати поділ маршрутів на публічні та захищені, створити сторінки входу і реєстрації, екран каталогу товарів, екран деталей товару, а також обробку неіснуючих маршрутів.

## Інструкція із запуску
1. Клонувати репозиторій:
`git clone https://github.com/hoowalex/MobileLabsRN2026`

2. Перейти в папку лабораторної роботи:
`cd /lab5`

3. Встановити залежності:
`npm install`

4. Запустити проєкт:
`npx expo start -c`

## Опис реалізованого функціоналу

У застосунку реалізовано мобільний каталог товарів із навігацією на основі **Expo Router** та принципу **file-based routing**. Структура папки `app` використовується для побудови маршрутів, а навігацію поділено на дві логічні групи: **публічні маршрути** для входу та реєстрації і **захищені маршрути** для доступу до каталогу товарів.

Для керування станом користувача створено глобальний контекст авторизації `AuthContext`, у якому зберігається значення `isAuthenticated`, а також реалізовано функції `login`, `register` і `logout`. Це дозволяє контролювати доступ до основної частини застосунку та виконувати перенаправлення неавторизованого користувача на екран входу.

У групі публічних маршрутів реалізовано:
- екран **входу** з полями для введення email і пароля;
- екран **реєстрації** з полями для введення імені, email, пароля та підтвердження пароля;
- переходи між екранами входу і реєстрації за допомогою компонента `Link`.

У захищеній частині застосунку реалізовано:
- головний екран із **каталогом товарів**;
- відображення списку товарів за допомогою `FlatList`;
- виведення зображення, назви та ціни кожного товару;
- кнопку **«Вийти»**, яка скидає стан авторизації;
- перехід на сторінку деталей товару при натисканні на картку.

Для перегляду повної інформації про товар реалізовано **динамічний маршрут** `details/[id].jsx`. На екрані деталей відображаються зображення товару, назва, ціна та детальний опис. Параметр `id` отримується за допомогою хука `useLocalSearchParams()`.

Також у застосунку реалізовано екран `+not-found.jsx`, який використовується для обробки неіснуючих маршрутів. Якщо користувач переходить на шлях, якого немає в структурі проєкту, відкривається сторінка з повідомленням про помилку та кнопкою повернення на головний екран.
